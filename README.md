# СИЛА. Калькулятор калорий

Одностраничный калькулятор стартовой калорийности и БЖУ для взрослых. Все расчёты выполняются в браузере. Параметры хранятся только в открытой странице и сбрасываются при её перезагрузке.

## Запуск и тесты

Откройте `index.html` в браузере. Для запуска тестов из корня проекта нужен Node.js 20 или новее.

```sh
node --test
```

## Правила расчёта

- Первичный расчёт использует формулу Миффлина — Сан Жеора и коэффициенты активности 1,20, 1,45 или 1,70. Для похудения применяется дефицит 10%.
- Перерасчёт работает самостоятельно или подставляет результаты последнего успешного первичного расчёта. При подстановке корректировка сбрасывается на «Без изменений».
- Вкладка «По БЖУ» переводит граммы белков, жиров и углеводов в килокалории по коэффициентам 4, 9 и 4 ккал/г соответственно. Допускаются дробные значения и нули.
- Первичный дефицит блокируется при текущем или целевом ИМТ ниже 18,5. Этот порог используется как ограничение автоматического расчёта. [Категории ИМТ CDC](https://www.cdc.gov/bmi/adult-calculator/bmi-categories.html)
- Оба инструмента блокируют результаты ниже 1 000 ккал/сутки и проверяют, что белки и жиры помещаются в рассчитанный бюджет. Порог 1 000 ккал/сутки используется для блокировки. [NIDDK Body Weight Planner](https://www.niddk.nih.gov/bwp.)
- Проверка ввода допускает возраст 18–120 лет, рост 100–250 см, вес 20–500 кг и исходную калорийность для перерасчёта 1–15 000 ккал/сутки.
